# Concept explanation quality rubric

Use this rubric to review an answer, not as a mandatory visible section. Score each dimension from 0 to 2. A strong answer normally scores at least 16/20 with no zero in definition accuracy, source discipline, or conceptual boundary.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Definition accuracy | Wrong or omits defining conditions | Broadly right but imprecise | Correct, scoped, and preserves defining attributes |
| Source discipline | Invented/mixed authority or unchecked quote | Source frame implicit | Governing source/context clear; conflicts separated |
| Beginner mental model | No usable intuition | Understandable but vague | Simple, accurate initial model |
| Problem and purpose | Missing | Purpose stated without causal setup | Problem → concept → effect is clear |
| Type-adapted mechanism | Wrong teaching form | Partly adapted | Structure matches object/process/metric/etc. |
| Example quality | Missing or circular | Concrete but incomplete | Continuous example exhibits defining attributes |
| Conceptual boundary | Missing or misleading | Names a neighbor | Gives decisive difference and useful non-example where apt |
| Analogy discipline | Misleading/unbounded | No analogy or limit unclear | Useful analogy explicitly states mapping and limitation; or wisely omitted |
| Knowledge connection | Isolated fact | Related terms listed | Parent, useful siblings, and next learning links are coherent |
| Retrieval and depth | No recall opportunity or badly sized | Check/depth partly suitable | Short central self-test and depth matched to learner |

## Review procedure

1. Identify any factual or source error first; stylistic polish cannot compensate for it.
2. Find the lowest-scoring dimensions.
3. Revise only where the score reveals a real learning failure. Do not bloat the answer merely to maximize visible headings.
4. Recheck that the beginner sentence and precise definition do not contradict each other.

## Drift checks across models or versions

For the same prompt, compare:

- whether the defining attributes remain unchanged;
- whether the eleven-part learning sequence remains recognizable;
- whether requested depth changes detail rather than correctness;
- whether source-specific meanings stay labeled;
- whether examples and self-tests target the same core concept.

Variation in phrasing is acceptable. Variation in governing definition, boundary, or depth contract is not.
